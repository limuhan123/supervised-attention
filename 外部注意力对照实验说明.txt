外部注意力对照实验

目的
在本项目固定P3/P4双尺度检测器上，对比常规检测驱动注意力与场坪语义监督。
新增E0（SE）和E1（CBAM），各运行seed42、43、44，共6次训练。
既有A0、A1、A2、A3作为参照；确认源代码、数据清单与AP口径一致后才复用旧结果。
若不能确认，启动脚本支持将这些参照一起重新训练。

实验组
A0：YOLOv8_small，检测基线，无场坪损失。
A1：YOLOv8_small_self_branch，branch_loss=0，学习g，无场坪损失。
A2：同分支，g固定为0，完整场坪损失，lambda=0.5。
A3：同分支，g从0.5学习，放缓场坪监督，完整损失，lambda=0.5。
E0：YOLOv8_small_se，P4处一个SE，reduction=16，无场坪损失。
E1：YOLOv8_small_cbam，P4处一个CBAM，reduction=16，空间核7，无场坪损失。
请勿误用旧YOLOv8_se或YOLOv8_cbam，它们使用不同的三尺度骨架。

结构公平性
新增两组直接继承YOLOv8_small，仅在backbone[5]卷积之后、backbone[6]的C2f之前插入模块。
基础骨架、颈部、检测头、通道数和深度保持一致，共享部分按相同种子初始化。
SE使用项目现有的无偏置1×1两层通道映射；CBAM采用作者代码结构：
带偏置的共享MLP、平均/最大通道池化、最大/平均空间池化、7×7卷积和BN。
原有三尺度模块及其检查点结构保留。
SE/CBAM使用自身的乘性门控，不另加g；这是标准模块接入对照，而非匹配门控形式消融。
模块输入是P4；A3的分支从P3生成响应。因此比较仍包含注意力来源和形式的差异。

固定训练协议
沿用原数据根目录的images/train、images/val与labels/train、labels/val，禁止重新随机划分。
预期567训练图、142验证图；请与原正式运行清单核对，不能仅凭数量判断相同。
只检测原标签0；原标签4只供A2/A3辅助监督；1、2、3仍忽略。
仍使用现有YOLO_Dataset的同步几何变换及默认增强，不启用Albumentations。
输入640，batch32，梯度累积2，AdamW，lr0.005，weight_decay0.0005，最多300轮，耐心30。
保持原训练脚本中的调度器、损失归一化、AMP、验证预处理与AP积分实现。
best按验证AP50–95选择；NMS前置信度0.001，IoU0.7，topk1000，max_det300。
不使用预训练权重，不为某个外部模块单独调参，不从三个种子中挑最好值。
启动脚本保存图像/标签SHA256和训练源码SHA256，拒绝覆盖已有运行目录。

运行方式（在项目根目录，使用服务器原训练Python环境）
先预览六个命令：
python run_external_controls.py --data_path /实际路径/data --device 0
正式执行：
python run_external_controls.py --data_path /实际路径/data --device 0 --execute
若需同时重跑参照：
python run_external_controls.py --data_path /实际路径/data --device 0 --experiments A0 A1 A2 A3 E0 E1 --execute
分卡运行时分别选择E0和E1，或设置不同--output；不要同时向同名运行目录写入。
仅执行一个种子时：追加 --seeds 42。
正式训练前可直接用train.py的--smoke_batches 1 --epochs 1，在独立save_dir做短程核验；
短程结果禁止并入论文。

报告方式
主表列：设置、场坪监督有无、AP50、AP50–95、参数量、GFLOPs。
AP报告三个种子的均值±样本标准差（ddof=1），统一以百分数显示。
补充表保留每个种子best轮次、停止轮次和两项AP，报告A3−E0和A3−E1的配对差值（百分点）。
参数量和GFLOPs取现有config.json的para_number和gflops；注意THOP对池化等算子计数的局限。
若补延迟，需同一GPU、batch1、640输入、相同精度、预热与CUDA同步；明确是否含NMS。
三个种子只反映同一划分下的训练波动，不直接声称统计显著。

解释边界
A3比E0/E1多用场坪框，这不是同监督预算比较，应在表中明确。
A3优于外部模块时，只能支持该任务和协议下完整方案的优势。
额外区域监督的收益主要依赖已有A3对A1对照判断，不能全部归因于结构。
没有超越外部模块也应保留结果，可结合A2与A3解释共享辅助训练和回注的作用。
本实验不解决原稿中独立测试集和切片空间独立性问题。
